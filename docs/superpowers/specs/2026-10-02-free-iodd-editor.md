# Approved free IODD editor

Provide a free browser-only IODD editor on iolinki.com, without signup or file
uploads. Users start from the released counter or switching-sensor template or
import an IODD XML file. Structured controls edit device identity, vendor
parameters and unconditional process-data records. Full XML remains available
for other features. Preserve all imported sections rather than rebuilding an
import from a reduced JSON representation.

Import validates XML syntax with DOMParser; reject DTD/entity declarations and
files over 4 MiB. Generic tree helpers and deterministic XML serialization reuse
MIT IODDForge Studio revision 95bdd7fff3fe52a8d2b013b9a07dccbb76555d4a. CRC reuses
existing pinned MIT IODDForge Checker. Retain licenses and provenance.

Provide actionable structural, index, reference, datatype/range and overlapping
bit diagnostics. Export identifies our checker and stamps the serialized bytes;
basic checks must not imply official checker or product-conformance approval.
Editing one supported section must retain unsupported sections, attributes,
comments and language records. Show raw XML editing for other structures.

Verify real browser imports, edits, downloads and responsiveness at 1440/390/320.
Validate downloaded examples using the released Python CLI and external official
IODD1.1 XSD. Keep checkout disabled and archived license terms immutable.

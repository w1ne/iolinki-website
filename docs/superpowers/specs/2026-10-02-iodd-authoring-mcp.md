# Shared IODD authoring and MCP

The user approved the shared browser/CLI/MCP authoring engine on 2026-10-02 and explicitly requested subagents. The existing XML-preserving model and CRC library remain the foundation. Build practical authoring rather than a collection of long forms.

## Architecture and contract

`assets/js/iodd/project.js` is browser-compatible and exports `createProject(xml, filename)`, `loadProject(json)`, `saveProject(project)`, `inspectProject(project)`, `applyOperation(project, operation)`, `validateProject(project)`, `exportProjectXML(project)`, `generateFirmwareHeader(project)`, `diffProjects(before, after)`. Projects are plain JSON `{format:'iolinki-iodd-project', version:1, filename, xml, assets:[{name,base64}]}`. All edits return a new project; failures leave the previous project untouched. XML import retains unfamiliar supported sections. `inspectProject` returns `{identity,variables,processData,assets}` using existing document getters.

Operations use `{type:'identity', values}`, `{type:'addVariable', values}`, `{type:'editVariable', id, values}`, `{type:'removeVariable', id}`, `{type:'editProcessField', id, index, values}`, `{type:'addProcessField', id, values}`, `{type:'removeProcessField', id, index}`, `{type:'text', language, id, value}`, `{type:'event', values}`, `{type:'menu', values}`, `{type:'asset', name, base64}`. Menu/event operations must follow actual IODD schema, preserve references and reject invalid input. Export returns stamped XML only after basic errors are resolved. Validation explicitly reports basic/model/CRC coverage; no official-conformance claim.

`assets/js/iodd/package.js` exports async `importPackage(Uint8Array)` and `exportPackage(project)` (Uint8Array). Validate names, duplicates, compression/expanded size and XML choice; preserve language/image files. Use pinned fflate with retained license. XML up to 4MiB, project/package expanded total 16MiB, max128 files, no absolute/traversal paths. Projects support save/reopen, revision comparison and firmware index/bit mapping header. Never generate a manufacturer declaration or official checker approval.

`tools/iodd/node-runtime.mjs` installs a tested XML DOM adapter for Node, allowing unchanged core imports. `tools/iodd/cli.mjs` offers create/import/inspect/edit/validate/export/diff/header with JSON output, meaningful nonzero exits and explicit file arguments. `tools/iodd/mcp.mjs` uses official MCP SDK stdio, typed tool schemas and session-local project IDs, bounded state, no arbitrary shell or network. Tools create/import/inspect/edit/validate/export/diff/header. Local stdio is runnable now; no unprovisioned public endpoint claim. An optional external official-checker command integration uses a user-installed checker and records actual output/status separately; do not redistribute it without reviewed permission.

The browser uses compact navigation for Identity, Parameters, Process data, Texts, Events/Menus, Files, Validation and XML. Parameters appear as searchable rows with one selected editing form. Process bits have a visual layout and add/remove actions. Keep no-upload privacy, keyboard access, mobile layout, atomic edits and pending XML protection. Provide project/ZIP/XML/header downloads, reopen and useful examples. Clear save status and actionable field checks. Do not change pricing or send email.

## Verification

Test new project mutation failures and roundtrips, ZIP content preservation/path/size rejection, Node/browser parity, real MCP handshake/list/call including bad inputs, firmware mapping export and revision diff. Browser tests cover end-to-end create/edit/save/reopen/package/download at desktop and mobile plus existing preservation/negative cases. Validate generated examples with released CLI and official XSD; run an installed official checker if available and report its status precisely. Connect firmware-generated indexes and process offsets to existing LabWired examples where feasible; distinguish static consistency, simulated execution and physical evidence. Review, merge and verify public website and downloadable MCP source.

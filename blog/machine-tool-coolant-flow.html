Coolant flow on a machine tool

Stop the cycle before the tool runs dry, and read the coolant temperature from the same sensor.

11 October 2026 · Andrii Shylenko

The problem

A clogged filter, a kinked hose or a worn pump cuts the coolant flow, and the pump itself raises no alarm. The machine keeps cutting, and the tool and the part pay for it within seconds.

The station

  • Sensor ifm SA5000, calorimetric flow and temperature, 45 mm probe, M18 x 1.5, port class A
  • Master Beckhoff EP6224-2022, 4 ports, EtherCAT. 1.4 A per port, 4 A total
  • Port X1, 6.4 m route, 10 m cable

The settings that matter

SettingValueWhyDatasheet / IODD
Operating moderelative (factory)Emulsion is not on the media list; teach the normal flow on the machine, then flow reads 0 to 100 %Media: water, glycol, air, oils. Relative mode is DeviceID 533
Switch point SP160 %“Flow OK” from 60 % of normal flowSP1 5 to 100 % (IODD)
Reset point rP150 %Drops at half the normal flowrP1 0 to 96 % (IODD)
In the PLC10 s, then 0.5 sIgnore the signal for 10 s after power-on. A flow loss arrives 0.5 s later (water)Power-on delay 10 s; response 0.5 s water, 0.8 s glycol, 1.8 s oil

The studio has no ISDU index for the operating mode, so the report lists it as a data gap. Relative is the factory setting, so a new sensor needs no write. The teach is done on the running machine.

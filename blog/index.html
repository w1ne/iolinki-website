One plant problem per post, one station that solves it. Built in the station studio; every post lets you turn the station and press Run.

  • A stainless part at a conveyor stop The clamp only closes when the part really sits on the stop. With stainless parts the sensor has to be set differently.
  • Pump discharge pressure that does not chatter One clean “pressure OK” signal for the PLC, with a set point and a reset point so the output does not flicker on pump ripple.
  • Tank level and overfill with one radar sensor The level in millimetres and a hard “full” switch from one sensor in the tank lid.
  • Coolant flow on a machine tool Stop the cycle before the tool runs dry, and read the coolant temperature from the same sensor.
  • Box detection on a conveyor Count the boxes, ignore the guard rail behind them, and get the distance to every box over IO-Link.

2. Ask for your first device

Create a switching-sensor IODD with my assigned vendor/device IDs and defaults. Inspect and validate it, export editable JSON/XML/ZIP, and save a recovery snapshot with its token kept private. Generate the source kit. If LabWired is connected, compile and verify the sensor application. Report schema, official Checker and execution results separately.

Open the exported project or ZIP in the browser editor to review and continue editing. Restore a saved snapshot in a new session using its private token; anyone holding the token can restore or delete it.

The 20 tools include firmware source and recovery. The sensor kit runs the released application on a modeled STM32F401 and checks thresholds, hysteresis, validity, parameters and process bytes. LabWired receives the submitted firmware source; report its actual verdict and model gaps. Physical IO-Link master, PHY and cable tests remain separate.

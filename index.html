01 / Device

For sensors
and actuators.

The iolinki device stack serves process data, mandatory parameters, events and ISDU services through a PHY abstraction for Zephyr and bare-metal systems.

  • Device-side application interface
  • Hardware-specific PHY integration
  • Host and embedded reference examples

02 / Master

For ports
and controllers.

The separate iolinki-master C library drives startup, cyclic process data, ISDU reads and writes, diagnostics, and SIO DI/DQ modes for master ports and multiport controllers.

  • Master-side port management
  • Independent master application API
  • Real device / master software testing
